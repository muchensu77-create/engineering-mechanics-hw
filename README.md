# 工程力学作业讲解

工程力学（理论力学与材料力学）P27 平面汇交力系第 6、7、11、12、13、14、15 题，P36 平面力偶系第 7、8、9、10 题，共 11 题的分步讲解网页。第 11 题按老师要求取 F₁ = 100 kN。

在线查看：https://muchensu77-create.github.io/engineering-mechanics-hw/

每题左边是受力图，点"下一步"或按 → 键，力会一步步画出来；右边是每一步的讲解，下方有作业本写法和答案。部分题目可以拖动滑块改变角度。

## 文件

- `index.html`：网页本体（单文件，不需要联网也能打开）
- `工程力学作业讲解.html`：和 index.html 内容相同
- `_src/`：源码。改完运行 `python _src/build.py` 重新生成上面两个文件
