# 工程力学作业讲解

工程力学（理论力学与材料力学）四章共 21 道作业题的分步讲解网页。

在线查看：https://muchensu77-create.github.io/engineering-mechanics-hw/

| 章 | 内容 | 题目 |
|---|---|---|
| 第一章 | 平面汇交力系（任务 1-2，P27） | 6、7、11、12、13、14、15（第 11 题按老师要求取 F₁ = 100 kN） |
| 第二章 | 平面力偶系（任务 1-3，P36） | 7、8、9、10 |
| 第三章 | 平面任意力系（任务 1-4） | 9、10、11、12、15、16 |
| 第四章 | 点的运动（任务 2-1） | 11、12、13、14 |

每题左边是图，点"下一步"或按 → 键，力会一步步画出来；右边是每一步的讲解，下方有作业本写法和答案。静力学的题最后有"受力平衡图"：把研究对象受的力平移到同一点，再首尾相接，看合力是否为零。第四章的机构可以播放运动。

## 文件

- `index.html`：网页本体（单文件，不需要联网也能打开）
- `工程力学作业讲解.html`：和 index.html 内容相同
- `_src/`：源码。改完运行 `python _src/build.py` 重新生成上面两个文件
